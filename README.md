This is a local interface for you to explore variations of lemma across regions in Finnic runosongs. You can search the word you want to explore in English translation and it will give you a map showing regional variations. You can also download cvs files including different levels of information.


**[How to use]**

#Download the package -> Install Streamlit & Run .py

cd ".....(Your cd)"
streamlit run apps/local_lexical_variation_app.py

****word_analysis.parquet is missing from the folder. Please prepare it and add it to the folder by yourself.****
